# Ante Up — Balatro companion

Fan-made companion for Balatro (v1.0.1 data). Pick your jokers and editions, check the three-legged stool (Chips / +Mult / xMult), get the left-to-right order, synergies, warnings and what to buy next. Plus hand values, build archetypes, every Boss Blind with a counter, and the method in tip cards.

Static site — `index.html`, `styles.css`, `app.js`, `data.js`. No build step. Hosts on GitHub Pages as-is.

- Edit joker data, combos, bosses, builds and tips in `data.js`.
- Table and calculator state live in `localStorage`; a table shares via the URL (`#jokers?t=sly.f,duo.p`).
- Method credit: Heatmiser's Steam guide *How to Win at Balatro With Early Decks*; cross-checked against BalatroHQ.
